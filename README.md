# Gestor de Tareas Web

Aplicación web interactiva desarrollada con tecnologías estándar del navegador (HTML5, CSS3 y JavaScript puro) que permite a los usuarios registrar, gestionar y hacer seguimiento a sus actividades diarias directamente desde la interfaz, sin necesidad de recargar la página.

## Funcionalidades principales

* **Agregar tareas:** Registro dinámico de nuevas actividades mediante un formulario validado sin recarga de página.
* **Marcar como completadas:** Alternancia visual del estado de cada tarea (pendiente / completada).
* **Eliminar tareas:** Remoción individual de actividades de la lista.
* **Contador en tiempo real:** Visualización dinámica del número exacto de tareas pendientes por realizar.
* **Actualización dinámica del DOM:** Manipulación directa de elementos HTML y clases CSS mediante JavaScript.

## Tecnologías utilizadas

* **HTML5:** Estructura semántica de la aplicación.
* **CSS3:** Diseño limpio, responsivo y basado en Flexbox.
* **JavaScript:** Lógica de eventos, manipulación del DOM y control de estado de la interfaz.
